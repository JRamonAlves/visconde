# Visão comportamental primeiro, visão técnica sob demanda

O mapa abre pela visão comportamental, em que os blocos são etapas como "validar pedido". O usuário aprofunda uma região para chegar à visão técnica, com funções, chamadas e estado. As duas são visões do mesmo mapa, e cada elemento técnico continua ligado ao comportamento que implementa. O aprofundamento acontece sob demanda para não gastar tokens com regiões que o usuário não vai explorar.
