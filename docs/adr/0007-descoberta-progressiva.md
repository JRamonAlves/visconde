# Descoberta progressiva com regiões não investigadas explícitas

O agente não lê o repositório inteiro antes de mostrar o mapa. A primeira análise termina quando o overview apresenta as principais responsabilidades, pontos de entrada e relações, com referências ao código. O que o agente ainda não leu aparece como região não investigada. Ler tudo é inviável em projetos grandes, e um mapa que omite partes sem avisar induz conclusões erradas.
