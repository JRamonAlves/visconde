# Editar pelo mapa significa selecionar e escrever o pedido

No modo edição, o usuário seleciona blocos ou relações e escreve o pedido de alteração. Arrastar ou conectar blocos não tem significado definido no alpha; vamos atribuí-lo a partir do uso real. Vale a partir da versão do alpha que introduzir edição (ver ADR-0012).
