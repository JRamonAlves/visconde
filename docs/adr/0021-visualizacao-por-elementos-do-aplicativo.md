# O agente compõe a visualização com elementos que o aplicativo renderiza

O agente decide o conteúdo e a organização, mas só pode usar elementos que o aplicativo sabe renderizar e tornar exploráveis: blocos, relações, agrupamentos, sequências e referências de código. Gerar HTML ou componentes livres a cada análise foi rejeitado porque seleção, aprofundamento, referências e contestação deixariam de funcionar da mesma forma entre projetos.
