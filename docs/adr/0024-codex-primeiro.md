# Codex é a primeira integração; Claude Code vem depois

A 0.0.1 integra apenas Codex, por meio do `codex app-server`. O Codex é open source, tem protocolo documentado para aplicativos de terceiros e permite compartilhar o plano ChatGPT em aplicativos locais e abertos. Claude Code continua no plano, mas a autenticação por assinatura em produtos de terceiros tem restrições documentadas que precisam ser esclarecidas antes. O contrato de adapter (ADR-0018) mantém o caminho aberto para o segundo agente. Isso substitui, para a 0.0.1, a exigência de suportar os dois agentes no alpha.
