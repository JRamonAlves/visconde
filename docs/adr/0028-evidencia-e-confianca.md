# Toda afirmação do mapa declara sua evidência

Cada bloco e relação tem uma confiança: `verificada`, quando o código mostra o fato diretamente, `interpretada`, quando é a leitura do agente, ou `não-investigada`. Blocos e relações técnicas exigem pelo menos uma referência de código. Um bloco comportamental sem referência direta precisa ter uma ligação de implementação até o código ou estar marcado como não investigado. O aplicativo rejeita qualquer elemento `verificado` que não tenha referência.
