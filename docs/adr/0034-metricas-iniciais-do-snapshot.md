# Métricas iniciais para avaliar o snapshot

Cada projeto de referência é avaliado por estas métricas:

- validade das âncoras;
- cobertura de pontos de entrada, comparada com uma lista feita à mão;
- precisão de uma amostra de relações interpretadas, revisada por uma pessoa;
- omissões graves, ou seja, fluxos conhecidos que não aparecem nem como região não investigada;
- honestidade das regiões não investigadas;
- custo em tokens, turnos e tempo até o overview;
- estabilidade ao revalidar sem mudança no código.

Aceitas para começar. O usuário vai revisá-las com calma, já usando o aplicativo.
