# O agente roda somente leitura na 0.0.1

A sessão do agente abre com sandbox somente leitura e sem aprovações de escrita. A única escrita permitida é no mapa, pelo servidor MCP do aplicativo. Assim, a garantia de que a 0.0.1 não edita código fica imposta pela configuração do agente, e não depende de uma instrução no prompt.
