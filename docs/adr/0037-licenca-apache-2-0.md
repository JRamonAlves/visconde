# Licença Apache-2.0

O Visconde é distribuído sob Apache-2.0. Ela é tão permissiva quanto a MIT e tem o mesmo suporte no GitHub. A diferença é que inclui uma licença explícita de patentes dos contribuidores, que se encerra para quem processar alegando violação de patente, e exige que forks indiquem os arquivos modificados. A AGPL-3.0 foi descartada porque não queremos impor copyleft.
