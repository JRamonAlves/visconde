# O local do snapshot é escolhido ao abrir o repositório, com o diretório do aplicativo como padrão

O usuário escolhe onde guardar o snapshot no momento em que seleciona o repositório. O padrão é o diretório de dados do Visconde: no macOS, `~/Library/Application Support/Visconde`; no Linux, `~/.config/Visconde`. Guardar em `.visconde/` dentro do repositório é uma opção explícita. Detalha o ADR-0033.
