# A lista de relações tem a saída `outra`

Além dos tipos fechados (ADR-0027), existe o tipo `outra`, que exige uma descrição. Sem ele, o agente encaixaria à força relações que não cabem em nenhum tipo. Os usos de `outra` mostram quais tipos acrescentar nas próximas versões do schema. A forma de exibir e de medir esse tipo fica para revisão.
