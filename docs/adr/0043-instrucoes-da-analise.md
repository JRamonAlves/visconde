# As instruções da análise vêm do Visconde e o agente consulta a documentação do projeto

As instruções de como montar o mapa ficam em arquivos versionados no repositório do Visconde e são enviadas a cada sessão. O agente também segue os arquivos de instrução do projeto analisado (`AGENTS.md`, `CLAUDE.md`) e consulta o `docs/` do projeto, quando houver. As instruções do Visconde tratam do mapa; as do projeto e a documentação dele explicam o código.

A documentação do projeto orienta a leitura, mas não substitui o código como evidência. Uma afirmação que vem só dos docs fica marcada como `interpretada` (ADR-0028).
