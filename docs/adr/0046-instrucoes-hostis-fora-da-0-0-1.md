# Defesa contra instruções hostis no repositório analisado fica fora da 0.0.1

Um `AGENTS.md` malicioso pode tentar manipular o agente. A 0.0.1 não trata esse risco além do que já está decidido: sandbox somente leitura (ADR-0036) e isolamento de configuração do repositório (ADR-0044). O tema volta antes de qualquer versão que permita edição.
